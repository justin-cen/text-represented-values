# 代码说明（code/）

本目录收录论文的可复现计算管线脚本（已剔除迭代过程、调试与一次性脚本）。运行环境：Windows / Python 3.13（依赖 pandas、pyarrow、sentence-transformers、trafilatura、matplotlib、scipy、ahocorasick、opencc-python-reimplemented、statsmodels）。多语嵌入模型 `intfloat/multilingual-e5-large` 与 `sentence-transformers/LaBSE` 经 HuggingFace 缓存离线加载（`HF_HUB_OFFLINE=1`）。

## 管线总览（按执行顺序）

### 阶段一：原始语料 → 统一语料
| 脚本 | 作用 |
|---|---|
| build_corpus.py | 各公开源（豆瓣、IMDB、THUCNews、XSum、Letterboxd、FineNews）→ 统一 13 列语料 |
| build_letterboxd.py | pkchwy Letterboxd 全量 dump → 英文影评语料（≥50 字） |
| build_aclimdb_films.py | aclImdb 原版 → 带 tt 影片编号的英文影评（urls_*.txt 映射） |
| build_genome_reviews.py | Tag Genome reviews.json → 带 tt 的 262 万英文影评 |
| scrape_zh_news.py / scrape_portals.py / finenews_pull.py / build_news_recent.py | 抓取人民日报系、新华/中新/央广、FineNews 西方新闻并整理 |
| resolve_douban_ids.py / fetch_douban_recent_v2.py | 豆瓣电影维表离线解析影片 ID → 移动端接口现抓近期评论 |

### 阶段二：统一语料 → 分析级配对集
| 脚本 | 作用 |
|---|---|
| make_analysis_sets.py | 历史/通用对照集抽样 |
| match_samefilms.py | 豆瓣×Letterboxd 片名匹配同片集（初版，已被年度消歧版取代） |
| rematch_by_year.py | **片名×年份双重消歧**的同片配对（主配对集 reviews_samefilms_v3） |
| build_chinese_films_matched.py | 华语片同片配对集 |
| build_douban_imdb_matched.py | 豆瓣×aclImdb/genome 的 tt 直连同片集 |
| build_reviews_recent_matched_v2.py | 同时代复核集（ID 一致性+年份双重校验） |
| build_political_corpus.py | 政治话语层合并（GWR/SOTU/国王演讲/SOTEU） |
| audit_years.py / verify_ids.py / sample_matched_subset.py | 配对质量审计与大集分层抽样 |

### 阶段三：词库冻结
| 脚本 | 作用 |
|---|---|
| freeze_lexicon.py | 锚定词＋LLM 扩充 → 机器筛查（内聚/区分度/对齐/频度）→ 冻结 v3 词库 |
| adjudicate_zero_freq.py / adjudicate_zero_freq_loo.py | 51 个零频锚定词的两级机器裁定（全语料频度复检 + 留一法影响检验） |

### 阶段四：嵌入与测量
| 脚本 | 作用 |
|---|---|
| embed_facet_similarity.py | **核心嵌入器**：词库质心 + 文本嵌入（e5/LaBSE 可切换），支持分块均值嵌入（`--doc-chunk-mean`）、断点续跑、温控保护、模型标签缓存 |
| check_e5_alignment.py | multilingual-e5-large 中英跨语言对齐效度检验 |

### 阶段五：分析与稳健性检验
| 脚本 | 作用 |
|---|---|
| analyze_sims.py | 文本内标准化、极性对比分、同片配对 t 检验、四体系画像 |
| analyze_political.py | 政治层按年配对 t 检验、SCV 分来源画像、三层体裁定位 |
| era_outlet_analysis.py | 11 层跨年代×跨体裁对照 + 分媒体稳健性 |
| criterion_check.py / wvs_criterion.py | Hofstede/WVS 调查基准的效标关联检验 |
| sensitivity_lexicon.py | 三版词库的文本级与组间对比分敏感性 |
| robustness_pack.py | Bootstrap 置信区间、FDR 校正、效应量、文化内安慰剂、长度混淆核查 |
| cross_model_consistency.py | e5 vs LaBSE 跨模型三角互证 |
| item_anchor_check.py | VSM2013 题项原文锚 vs 冻结词表的构念效度对照 |
| test_retest.py | 政治长文档文内分半一致性 |

## 运行约定

- 全部嵌入脚本默认 **CPU**（`--device cpu --threads 4–6`），GPU 需显式 `--allow-gpu`（本机 GPU 散热故障，文档实验均 CPU 完成）。
- 嵌入缓存按 `{集名}_{模型标签}.npy` 落盘于 `emb_cache/`，断点可续跑。
- 结果输出至 `data_corpus/results/`。

## 论文渲染

论文 docx 由 `specifications/docx_builder.py`（依赖 `omml_latex.py`、`template_src/`）从 `paper/source.xmd` 从零渲染：

```
python specifications/docx_builder.py paper/source.xmd out.docx
```
